\chapter*{\uppercase{ABSTRACT}}
\addcontentsline{toc}{section}{\bfseries \uppercase{Abstract}}
AI agents without persistent memory forget instructions and project decisions when a
session ends. When an instruction changes, they often keep using the old one. For this
project we built a long-term memory engine in Rust for such agents. What it stores
carries over between sessions, can be corrected later and can be traced back to the
original messages.

The engine has five modules: source acquisition and processing, knowledge extraction
and consolidation, temporal knowledge and graph management, hybrid retrieval and
grounded reasoning, and model training and evaluation. Original messages are stored
unchanged as source events. The engine extracts assertions (typed statements about the
user or project) together with the exact quote they came from. Assertions are stored as
versions, so a correction replaces an old value without deleting it. Retrieval combines
keyword, vector, time and graph search with Reciprocal Rank Fusion. Each result comes
back with its source quotes. A small local Qwen3-4B model, fine-tuned with QLoRA, does
the extraction and answering.

We tested the engine on LoCoMo, a public benchmark of ten long conversations (1,540
questions). Every setup used the same reader model and two model judges. With the engine
the reader answered 83.1\% of the questions correctly. Plain retrieval over the raw text
scored 80.0\%, keeping only the last 8,192 tokens scored 43.0\% and no memory scored
0.3\%. The whole conversation scored 89.0\% but used more than three times as many
tokens. All 99,971 source quotes returned by the engine matched the conversation exactly.
Our scripted tests showed that corrections keep their history and that the engine refuses
to answer without evidence. They also caught a date bug, which we fixed after the test.
