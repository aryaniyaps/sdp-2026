Memory Engine benchmark¶

This notebook is the evidence for the claim that the memory engine is useful to an agent. Every number below is recomputed here from the stored run records in benchmark/runs/. No model is called and no service is touched, so Run All takes seconds.

What was measured. LoCoMo [Maharana et al., ACL 2024] has ten long two-person conversations (272 sessions) and 1,540 scored questions about them. Each conversation is retained into the engine as its own memory bank. Each question is then answered by the same reader model under six conditions that differ only in what the reader is shown:

condition what the reader sees
enhanced the full engine: extracted assertions with source quotes, inferences, graph, temporal planning
raw_hybrid the engine's lexical + vector search over raw source chunks (plain RAG)
recent_window the newest 8,192 tokens of the conversation, the same budget as the engine: what an agent without memory keeps
full_context the whole conversation (an upper reference, and the most expensive)
no_memory the question only
no_graph, no_consolidation enhanced without one module (300-question stratified sample)

Two judges from different model families grade every answer with Mem0's LoCoMo rubric: TypeSafe Jev, a decision model (primary), and gpt-4o-mini, the judge Mem0 used. Mem0's token F1 and BLEU-1 need no model at all. A separate deterministic property suite checks knowledge updates, relative dates, abstention, attribution and credential filtering on the engine's stored state.

How to check it. benchmark/README.md shows how to re-run any stage. run.py verify rebuilds every stored prompt from the stored retrieval and the pinned dataset, and verify --live N re-asks the models on N random items. The spot-check section below prints random items in full so a reader can grade them by hand.

13. Comparison with published systems¶

Published LoCoMo results from the Mem0 paper (Chhikara et al., 2025, Tables 1 and 2), checked against the paper and stored in benchmark/published.json. They answer with GPT-4o-mini and this benchmark answers with Claude Haiku 5.5, so absolute scores are not comparable. The fair comparison is each system's distance from its own full-context baseline and the context it needs.
